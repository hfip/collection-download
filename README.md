# Collection Download

Small, self-contained HTML tools for Arabic media libraries. No build step, no server — open the file in any browser.

| File | What it does |
|---|---|
| `arabic-poster.html` | Arabic poster generator — renders RTL titles onto poster images |
| `arabic-poster-v3.html` | Newer version with improved layout and typography |
| `fusion-downloader.html` | Fusion Collections downloader — fetches a collection and saves it for import |

## Usage

1. Download the repository (or open the HTML file directly).
2. Open the page in your browser.
3. Follow the on-screen inputs; everything runs locally in the page.

## Notes

- Pure HTML/CSS/JS — no dependencies, no tracking, no network backend.
- Generated files are meant for personal library use only.
